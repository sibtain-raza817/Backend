## 📅 Day 2

### ✅ Topics Covered

### 🔹 Backend & Frontend Connection
Learned the basic communication between the frontend and backend. The frontend sends an HTTP request to the backend, the backend processes the request, interacts with the database if needed, and sends a response back to the frontend.

---

### 🔹 Import & Export
Learned how to split JavaScript code into multiple files using ES Modules. The `export` keyword is used to make variables, functions, or classes available to other files, while `import` is used to access them, making the code more organized and reusable.

---

### 🔹 Render
Render is a cloud platform used to deploy web applications, APIs, and databases. It automatically builds and hosts applications directly from a GitHub repository.

---

### 🔹 Railway
Railway is a deployment platform that allows developers to quickly deploy backend applications and databases with minimal configuration. It provides an easy way to host Node.js applications.

---

### 🔹 Cyclic
Cyclic is a serverless deployment platform designed specifically for Node.js applications. It enables developers to deploy backend projects directly from GitHub with a simple workflow.

---

### 🔹 Why `"type": "module"`?
Adding `"type": "module"` inside the `package.json` file tells Node.js to use the ES Module system. This allows us to use modern JavaScript syntax such as `import` and `export` instead of the older `require()` and `module.exports`.

---

### 🔹 `npm create vite@latest .`
This command creates a new Vite project in the **current directory**. The `.` (dot) tells npm not to create a new folder and instead initialize the project where the command is executed.

---

### 🔹 CORS (Cross-Origin Resource Sharing)
CORS is a browser security feature that controls whether a frontend running on one origin (domain, port, or protocol) can access resources from another origin. The backend must explicitly allow these requests using CORS.

---

### 🔹 Proxy
A proxy acts as an intermediary between the frontend and backend during development. Instead of calling the backend directly, the frontend sends requests to the proxy, which forwards them to the backend. This simplifies API calls and helps avoid CORS issues.

---

### 🔹 Data Modelling (Introduction)
Data modelling is the process of planning how data will be stored and organized inside a database. It helps define entities, their properties, and relationships before building the actual database. Today I only got an overview and will study it in detail on Day 3.
